SnehaSparsham – Touch of Love 

Project Overview

SnehaSparsham – Touch of Love is a web-based elder-care management application developed as my BCA final-year project. It aims to organize essential care activities for senior citizens through a centralized platform.

Key Features

- Medicine Schedule Management: Organizes medication schedules.
- Health Record Monitoring: Maintains health records and vital information.
- Diet Plan Management: Helps manage diet plans for senior citizens.
- Emergency Alerts: Supports emergency-related notifications.
- Care Coordination: Helps organize essential elder-care activities.

Technologies Used

- Backend: Python, Django
- Database: SQLite
- Frontend: HTML, CSS, JavaScript 

Project Objective

The main objective is to support the organized management of senior citizens' daily care activities through a simple web application.

Learning Outcomes

Through this project, I gained practical experience in Django application development, database management, backend logic, and integrating different features into a web-based system.
